# BizdinAlem — онлайн-библиотека для детей

Фронтенд на чистом HTML / CSS (БЭМ) / JS. Бэкенда пока нет — сайт работает в демо-режиме.

## Онлайн-версия (GitHub Pages)

**https://yenusian.github.io/bizdin-alem/**

Публикуется автоматически из ветки `main`: после каждого `git push` сайт обновляется через 1–2 минуты.
Включается один раз: репозиторий → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**.

Все пути в проекте относительные (`../css/styles.css`, а не `/css/styles.css`), поэтому сайт работает и на localhost, и в подпапке GitHub Pages. Новые страницы и картинки подключай так же — относительными путями. И следи за регистром в именах файлов: на GitHub Pages `Logo.svg` и `logo.svg` — разные файлы.

## Как открыть на localhost

Запускай сервер из корня проекта — из папки, где лежит `index.html`.

**Вариант 1 — VS Code + Live Server**
1. `File → Open Folder…` → выбрать именно папку `bizdin-alem` (не папку выше).
2. Правый клик по `index.html` → **Open with Live Server**.
3. Откроется `http://127.0.0.1:5500/index.html`.

**Вариант 2 — терминал (Python)**
```bash
cd bizdin-alem
python -m http.server 5500      # на macOS/Linux может быть python3
```
Открыть `http://localhost:5500`

**Вариант 3 — терминал (Node)**
```bash
cd bizdin-alem
npx serve . -l 5500
```

Swiper лежит локально в `vendor/swiper`, так что слайдеры работают и без интернета (без интернета подменятся только шрифты Google Fonts).

## Вход на сайт и доступ (`js/auth.js`)

1. По ссылке на сайт сначала открывается приветствие: `welcome-light.html` или `welcome-dark.html` (по теме посетителя).
2. Кнопка «прочитать» ведёт на главную. Если человек не зарегистрирован, его перекидывает на регистрацию, а после неё — на главную.
3. Без регистрации открыты только приветствие, регистрация и «О проекте». Если открыть по прямой ссылке любую другую страницу, сначала будет регистрация, потом — эта страница.
4. «Выйти» в панели ☰ стирает регистрацию и снова показывает приветствие.

Регистрация хранится в браузере посетителя (`localStorage`), это демо-защита, а не настоящая. Когда будет бэкенд, проверку в `js/auth.js` нужно заменить на проверку сессии с сервера.

## Демо-режим (`js/demo.js` + `css/demo.css`)

- Все кнопки, карточки книг и ссылки ведут на нужные страницы.
- Регистрация «создаёт» пользователя в `localStorage` и открывает профиль его роли; кнопка в шапке становится «Мой профиль», «Мои книги» ведёт в этот профиль.
- В читалке листаются 7 страниц сказки (кнопки, точки, стрелки ←/→). Плеер играет тихую дорожку — чтобы была настоящая озвучка, положите mp3 в `assets/audio/` и впишите путь в `AUDIO_SRC` в начале `js/demo.js`.
- Вместо `alert()` показываются аккуратные уведомления.
- Кнопка ☰ в левом нижнем углу — панель «Все страницы» для показа заказчику. `Shift + D` — скрыть/показать, `?demo=off` в адресе — выключить совсем, `?demo=on` — вернуть. Там же «Сбросить демо-данные».

Когда появится бэкенд: удалить `js/demo.js`, `css/demo.css` и их подключения в HTML.
